## 01 Context · Data Requirements

**Required sources, and exclusions**

Slack Internal Chats - All References with "RocketShip Pro comms"
Slack Customer Communications - Signal based on Align Slack Channels with Customer names from the Customer List file in Context storage. 
JIRA Epics and Initiatives - Space RocketPro and SecurityRockPro boards (Any Ticket starting with RP or SRP)
Salesforce Cases associated with Queue 'RocketPro'
Notion Documents referencing "RocketShip"
Sharepoint Document Folders in this location (LOCATION LINK) -  It can see Raw Signals, Product Strategy One-Pager and Roadmap files. Excluded anything outside these parameters or other tools even if they are used for RocketPro purposes.

**How fresh must it be**

Real time Change after Context Document change approval from PM or PO. Context Documents need to be able to be refreshed on demand. New context documents added to source files locations need to be allowed, but restrictred and secure. Files and Documents need to be a complete replacement, not an add on. File location needs to be secure and require PM or PO to be able to switch or change. document context. If a source is unreachable, continue with the agent, but create a notification to identify an issue. If a new context document is updated or added, that should be flagged on any brief for 2 days after refresh. Creating a context file history/version view for PMs and POs is required, thought his could be in the application.
